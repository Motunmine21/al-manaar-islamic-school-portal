# Al-Manaar Islamic School Portal

## Project Overview
Al-Manaar Islamic School Portal is a web application designed to provide information about the school, allow online admissions, and enable administrators to manage applications and announcements.

## Features
- Public Pages (Home, About, Academics, Contact)
- Online Admission Form
- Admin Login
- Admin Dashboard
- Announcements Management

## Technologies Used
- React (Vite)
- Firebase Authentication
- Firebase Firestore
- React Router

## Project Structure
src/
  components/
  pages/
  admin/
  firebase/
  routes/

## Deployment
The application will be deployed using Firebase Hosting.
